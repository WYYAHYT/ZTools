# 产品愿景

- Status: accepted
- Baseline: 0.1
- Last updated: 2026-08-21

## 愿景

ZTools vNext 希望成为一个快速、可靠、可扩展的桌面效率入口：用户用统一的搜索框发现应用、文件、命令和插件动作，并在不牺牲系统安全边界的前提下完成复杂工作。

它不是旧项目的重构版本，而是吸收旧项目经验后重新定义的平台。成功不以“复制所有旧 API”为标准，而以用户任务是否自然、安全、跨平台地完成为标准。

## 面向的人

- 希望用键盘快速启动、搜索和执行动作的普通用户。
- 希望把常用工作流集中到统一入口的专业用户。
- 希望使用清晰 API、稳定权限模型和可调试工具构建扩展的插件作者。
- 需要在 Windows、macOS 或 Ubuntu GNOME Wayland 上部署一致工具体验的团队。

## 核心体验

1. 用户通过快捷键或桌面入口召回主窗口。
2. 搜索结果快速合并宿主数据源、系统能力和插件贡献。
3. 每个结果清楚表达将要执行的动作、所需权限和平台限制。
4. 插件可以提供独立 UI 和后台任务，但不能突破其声明的能力边界。
5. 能力不可用或授权被拒绝时，产品给出稳定、可恢复的降级路径。

## 成功标准

- 常用入口响应稳定，搜索结果增量返回且不会被单个插件阻塞。
- 插件崩溃、超时或恶意行为不会拖垮宿主或访问未授权资源。
- 三个目标平台共享产品语义、插件契约和主要用户流程。
- Wayland 上的限制公开可见，不通过脆弱或欺骗性手段模拟完整能力。
- 新能力可以沿清晰模块边界增加，不需要修改无关领域代码。

## 不追求的方向

- 不做通用浏览器或完整 IDE。
- 不承诺首阶段兼容所有旧插件和旧内部 API。
- 不用任意 Node.js 访问作为插件扩展性的基础。
- 不以隐藏平台差异来制造虚假的“完全一致”。
- 不在核心体验稳定前建设云同步、团队协作或大型插件商业生态。
