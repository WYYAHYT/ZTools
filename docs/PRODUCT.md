# 产品范围

- Status: accepted
- Baseline: 0.1
- Last updated: 2026-08-21

本文件定义已接受的首阶段产品边界。它不代表功能已经实现；具体纵向切片仍需在对应 Gate 前形成可验收规格。

## 首阶段核心任务

- 可靠召回和隐藏主窗口，并尽可能恢复之前的应用焦点。
- 对宿主命令、应用、文件与插件贡献进行统一、增量搜索。
- 展示和执行结果动作，支持键盘优先交互。
- 安装、启用、禁用、升级和卸载安全插件。
- 运行插件 UI 与独立后台 Worker。
- 展示插件权限，按动作请求授权，并允许用户查看和撤销授权。
- 在设置中显示平台能力、授权状态、降级原因与诊断信息。

## 可信 Host UI

以下功能属于产品信任根的一部分，直接由宿主实现：

- 主搜索与结果界面。
- 设置和诊断。
- 插件安装与市场界面。
- 账号界面（进入相应阶段后）。
- 权限中心与授权说明。

这些功能不得作为拥有隐藏权限的普通插件实现。

## 插件可贡献内容

- 可搜索的命令与动作。
- 结构化搜索结果和结果预览。
- 受沙箱保护的交互界面。
- 经授权的宿主能力调用。
- 受资源配额与生命周期管理的后台任务。

插件不能假定 Node.js、Electron、任意文件系统、任意网络、裸 IPC 或宿主内部数据库访问。

## 首阶段非目标

- 云同步和多设备状态合并。
- KDE、wlroots 或所有 Linux 桌面环境的完整能力承诺。
- 任意原生二进制插件。
- 无限制常驻后台进程。
- 宏录制、隐蔽输入注入或绕过系统权限的自动化。
- 首阶段直接运行旧插件；未来若要引入兼容运行时，必须先接受新的兼容 ADR。

## 产品级质量属性

- 性能：交互线程不能等待插件或平台慢调用；搜索采用预算、取消和增量结果。
- 可靠性：插件、平台 Adapter 与 Portal 会话失败应隔离并可恢复。
- 安全：插件最小权限，所有跨信任边界输入都验证。
- 可访问性：主流程支持键盘、屏幕阅读器语义、缩放和高对比度。
- 可诊断性：用户能看到能力不可用、授权被拒绝或插件超时的原因。
- 可迁移性：数据格式、插件协议和 RPC 契约从首次发布起版本化。

## 验收规格的形成时点

本文件只冻结产品边界，不提前猜测尚未测量的性能数字。进入 Gate 2 前必须形成首个宿主纵向切片验收规格，至少明确：

- 核心用户旅程的优先级和开始/结束状态。
- 主窗口召回、查询、首批结果、取消和动作执行的可观察结果。
- 空查询、结果迟到、重复结果、动作失败、离线和网络不可用的用户语义。
- 在三个目标平台上的能力差异与允许降级。
- 性能测量方法、基线、目标值及超标处理，而不是只写“快速”。
- 键盘、屏幕阅读器、缩放、高对比度等最低可访问性依据。
- 首阶段本地化范围。
- 数据保留、插件卸载和应用卸载后的用户预期。

该规格在 [OPEN_ITEMS.md](OPEN_ITEMS.md) 中登记，未接受前阻断 Gate 2 实现。
